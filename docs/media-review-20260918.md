# 全站配图逐对象修复 · 2026-09-18

## 本轮范围与实际修复

用户要求检查大埃及博物馆重复配图，扩展检查全部景点并重新部署完整站点。本轮检查 14 个景点的 148 个图片位置：14 张封面、28 个外观／内部章节、106 条对象解读；改正或重新分配 113 个位置，保留主体合适的既有照片。首页、目录与四个城市页使用的封面同时检查。未缩小为单馆站点，未修改欧洲行项目或引入私人订单原件。

原问题不是只有相同文件重复：GEM 的多个年代章节分配了同一拉美西斯巨像的不同角度，大楼梯使用导视牌；其他页面存在墓室用山谷、柱像厅用外观、鳄鱼用壁面等主体错配。原函数还会在索引超出时退回第一张图片。新的运行数据按景点和对象 ID 严格绑定，缺少审核图片即抛出错误，不再自动填图。

GEM 现在分别使用书记员、中王国王像、埃赫那吞头像、Nesptah 石棺、托勒密捐赠碑、图坦卡蒙黄金面具、胡夫船、大楼梯、展厅及窗外吉萨地景。NMEC 的纺织、王像、游行、史前器物和皇家木乃伊不再共用主展厅全景。KV2、KV6、KV9、KV62 分别对应自己的墓内照片。卢克索庭院与大柱廊区别处理。

## 逐图证据与呈现

- `public/images/reviewed/manifest.json`：148 个位置的旧路径、新路径、中文主体说明、原始文件页、作者、许可、日期与 SHA-256。
- `docs/qa/media-audit/baseline.json`：修复前实际运行目录的图片快照。
- `docs/qa/media-audit/research-index.json`：本轮选图时固定的候选元数据。搜索结果只是候选，不是自动绑定依据。
- `scripts/media-selection.json`：逐对象的人工视觉选择。
- `src/data/reviewed-guide-media.generated.json`：运行时使用的确定映射。

148 个位置均经本地原图／联系表检查；106 条独立解读没有相同 SHA-256 的照片重复。哈希测试只防文件重复，不代替主体核对。封面与正文在需要时可合理展示同一建筑的不同尺度；未承诺每个建筑只能出现一次。

所有图使用真实来源照片，无生成式修改。来源缩略图保存在本地离线包。正文显示具体中文图注，并可打开作者来源页及许可证。图像完整适配，不为填满容器裁掉主体；图注不再覆盖照片。皇家木乃伊的历史照片、阿布辛贝迁移模型和红海生态参考的性质直接写明，不冒称今天的展厅、原位建筑或本次船程保证目击。

已核对全部最终选图联系表。实际网页另测桌面 1440、平板 1094、手机 390 三种宽度：42 个景点页面视图、444 次图片显示核对、106 次放大／关闭交互，无缺图、错误资源路径或横向溢出。手机为 Chrome 仿真，不是实机触控测试。代表性原尺寸卡片、外观／内部章节及全体页面截图保存在本地 `artifacts/media-local/`。
