# Single-guide publication review

Scope: publish the existing NMEC guide independently. This release contains 10 selected thematic interpretations, not the entire museum collection. Two source-backed floor layers and the existing integrated exterior model are retained; no new exhibit coordinates, floor connections, navigation or measured elevations were added.

Privacy: no itinerary, booking, flight, hotel, passenger identity, user screenshot or other destination data was copied. Only the selected guide's public source records and referenced assets are present. Repository and Pages cache namespaces are independent.

Media review: entrance photograph checked against the actual facade; hall photograph shows display cases and a high ceiling, not the rejected tourism sign. All 9 distinct photographs were viewed. Commons metadata identifies Roland Unger (2017 entrance/hall) and Onceinawhile (2022 images), CC BY-SA 4.0. General hall views are explicitly contextual photographs, not identifications of particular textiles or ancient objects. The royal-cache image is a historical exhibition panel, not a photograph of a royal mummy. Full author/license records are included. No AI-generated building or object images.

Spatial review: export retains two orthographic NMEC Figure 5-derived layers, nine selectable spaces and the previously constructed 200-part exterior. Initial interior opens the mapped entrance hall in 2D. Browser tests compare exact label identities/text at minimum and maximum zoom on both floors; inspect first/middle/last spaces, floor changes, drag/reset, exterior 2D/3D and front/oblique views. Reset views fit the subject. Interactive rotation may move the subject outside the viewport; reset restores it. Floor relationships do not imply a documented inter-floor visitor route.

Visual review: real Chrome, desktop 1440×1000, narrow 1094×768 and emulated phone 390×844. Inspected hero, full-page layout, both floor plans, reset 3D and exterior captures; no horizontal page overflow or failed images. No physical mobile-device or multi-touch validation is claimed. Forced WebGL failure is a simulation, not a reproduced hardware failure.

Offline: tests execute the real Service Worker and Cache API. A test server interrupts one resource with HTTP 503, a page is closed/reopened, and the missing resources resume. A partial version update preserves a previously complete release for an offline deep link; completion retires the old package while leaving an unrelated cache untouched. This is file-level resume, not byte-range resume. No permanent browser-storage guarantee.

The full browser and resume reports are stored beside this review. Previous failed test attempts were not counted as passes; final checks use the build release recorded by the offline manifest. A large lazy-loaded Three.js chunk warning remains; it is not a failed build.
